# 🎓 Student GPA Calculator

A simple **C# console application** that calculates a student's GPA based on their course grades and credit hours.

## 📌 About

This project was created as a practice exercise while learning the fundamentals of **C#**.

The program stores information about a student and their courses, calculates the weighted GPA, and displays the results in the console.

## ✨ Features

* 👤 Student information
* 📚 Course names and grades
* 📝 Credit hours for each course
* 🧮 Weighted GPA calculation
* 🖥️ Formatted console output

## 🛠️ Technologies

* **C#**
* **.NET**

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/csharp-student-gpa-calculator.git
```

2. Open the project in your preferred C# IDE.

3. Run the project:

```bash
dotnet run
```
